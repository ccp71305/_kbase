## 1. Overview

**Purpose:** `dispatcher` is the **S3→SQS routing gate** of the ETL pipeline. It consumes S3 `ObjectCreated` notifications (raw S3→SQS or S3→SNS→SQS), resolves the MFT id and archive-format type from the object key, optionally unzips container files (re-landing each entry in S3 so it re-enters the pipeline as its own event), copies the inbound object into the workspace bucket, and routes a `MetaData` envelope to the correct downstream splitter queue (or the booking-bridge queue for `300_IFTMBF` bookings) while emitting `START_WORKFLOW`/`CLOSE_WORKFLOW` lineage events.

- **Current state:** DW5 baseline; still on **AWS Java SDK v1 (1.12.720)** + `shared` for SQS (`SQSClient`/`SQSListener`/`AsyncDispatcher`), S3 I/O (`WorkspaceService`/`S3WorkspaceService`), SNS-envelope parsing, the workflow model, network-services, and health-check base.
- **Target:** `commons` + `cloud-sdk-api`/`cloud-sdk-aws` (`1.0.27-SNAPSHOT`) + slim `appianway-commons` (`AsyncDispatcher`, `ErrorHandler`/`RecoverableException`, error codes, health-indicator glue). AWS SDK v2 arrives transitively via `cloud-sdk-aws`.
- **Headline change:** dispatcher keeps its **S3-event parser dispatcher-local** (not promoted to cloud-sdk; O-G3 is optional-upstream, single-consumer) and is the module that exercises **S-G2** on the *write* path — `ZipPreprocessor` unzips a container and writes each entry back to S3 **with user metadata and content-type** via `StorageClient.putObject(bucket,key,bytes,metadata,contentType)`.

## 2. Current vs Target architecture

```
BEFORE — dispatcher on shared + AWS v1
  pickup SQS ─▶ shared SQSListener + AsyncDispatcher ─▶ DispatcherTask.process(Message, queueUrl)
       DispatcherTask ─▶ S3EventParser (v1 S3EventNotification.parseJson)
       DispatcherTask ─▶ PreProcessors (Ignore, Zip) ─▶ shared S3WorkspaceService (wraps AmazonS3 v1)
       DispatcherTask ─▶ RouterManager ─▶ shared SQSClient (wraps AmazonSQS v1)
       DispatcherTask ─▶ shared EventLogger
       DispatcherErrorHandler (extends shared ErrorHandler) ─▶ SQSClient + EventLogger
       ExternalServicesModule binds AmazonSQS(listener+sender)/AmazonS3/AmazonSNS (v1) + shared networkservices (SSM auth)

AFTER — dispatcher on commons + cloud-sdk (AWS v2)
  pickup SQS ─▶ appianway-commons SqsListener/Listener + AsyncDispatcher ─▶ DispatcherTask.process(QueueMessage[String], queueUrl)
       DispatcherTask ─▶ S3EventParser  [DISPATCHER-LOCAL Jackson record; unchanged behavior; O-G3 optional future promotion]
       DispatcherTask ─▶ PreProcessors (Ignore, Zip) ─▶ cloud-sdk-api StorageClient  (+ S-G2 putObject(...,metadata,contentType))
       DispatcherTask ─▶ RouterManager ─▶ cloud-sdk-api MessagingClient[String]
       DispatcherTask ─▶ cloud-sdk-api notification.workflow NotificationService/EventLogger
       DispatcherErrorHandler (extends appianway-commons ErrorHandler) ─▶ MessagingClient + NotificationService
       ExternalServicesModule factory-binds MessagingClient[String]/StorageClient/NotificationService (cloud-sdk-aws) + commons networkservices (same SSM auth)
       cloud-sdk-aws ─▶ AWS Java SDK v2 BOM
```

## 4. Sequence — consume → unzip+put(metadata) → route

**Primary flow: S3-event → route to splitter / booking-bridge**

```
 1.  SqsListener + AsyncDispatcher (appianway-commons) ─▶ receiveMessage (long-poll, wait=20s, max=10)
 2.  DispatcherTask.process(QueueMessage[String] msg, queueUrl)
 3.  body ─▶ SNSNotification.getMessage() (unwrap SNS envelope, if present)
 4.  S3EventParser.parse(innerJson) ─▶ S3Event{bucket, URL-decoded key, size, createdTime}
 5.  resolve mftId + archiveFormatType from key (path segments == 5)
 6.  StorageClient.getMetaData(bucket, key) ─▶ Map[String,String] user metadata
 7.  PreProcessors.execute(s3Event, msg, queueUrl):
       IgnorePreprocessor rejects (mftId/format not in active integration profiles) ─▶ throw AbortProcessingException ─▶ skip
       fileName ends .zip ─▶ ZipPreprocessor (see below) ─▶ throw AbortProcessingException (each entry re-enters pipeline)
       normal file:
         if archiveFormatType == 300_IFTMBF and xlogId present:
             MessagingClient.sendMessage(bookingBridgeQueueUrl, metaData.toJsonString()); logCloseRunEvent(START_WORKFLOW, success)   [return]
         else if s3Event.isValid() (nonzero size):
             StorageClient.copyObject(srcBucket,srcKey → inttra-int-workspace, workspaceFileName)   [no metadata]
             RouterManager.getRoutingQueue(metaData)  [FILE_TYPE → queue, default = splitter_pu]
             MessagingClient.sendMessage(routedQueueUrl, metaData.toJsonString()); logCloseRunEvent(START_WORKFLOW, success)
         else zero-byte object ─▶ throw EmptyMessageException ─▶ DispatcherErrorHandler
```

**Zip preprocessor: unzip → put-with-metadata (S-G2)**

```
  ZipPreprocessor:
    StorageClient.getS3InputStream(bucket, zipKey)
    for each ZipEntry:
        read entry bytes (software.amazon.awssdk.utils.IoUtils.toByteArray)
        StorageClient.getMetaData(bucket, zipKey)  [rootworkflowid / xlogid / originalfilename]
        ensure rootworkflowid present (generate if absent)
        StorageClient.putObject(bucket, folder+entryName, bytes, metadataMap, contentType)   [S-G2]
            ─▶ PutObjectRequest.metadata(map).contentType(...).contentLength(bytes.length)
        publishCloseRunEvent(initialMetaData, tokens incl. inboundS3ZipFileName)
    Note: each unzipped entry lands in inttra-int-workspace and is picked up as a fresh S3 ObjectCreated event, re-entering the dispatcher pipeline
```

**Failure / retry path (inherited, appianway-commons)**

```
  DispatcherErrorHandler / ErrorHelper:
    getAttributes().get(FAILED_ATTEMPTS)
    recoverable and under max ─▶ sendBackToPickupQueue(...) with FAILED_ATTEMPTS=n+1
    non-recoverable or exhausted ─▶ MessagingClient.sendMessage(subscription_errors, metaData.toJsonString())
```

### 5.2 SSM parameters

| Secret | SSM path | Today | After | `usePassThrough` |
|---|---|---|---|---|
| network-services `clientId` | `/inttra/int/appianway/networkservices/authclientid` | resolved **at runtime** by shared `AuthClient` (via `ParameterStoreModule`) | **keep runtime resolution** via commons `client.AuthClient` + `CloudParameterStore`, same lazy-fetch semantics (no yaml shape change) | `false` |
| network-services `clientSecret` | `/inttra/int/appianway/networkservices/authclientsecret` | same | same | `false` |

**Why keep runtime resolution instead of boot-time `${awsps:/path}`:** dispatcher's `clientId`/`clientSecret` yaml fields are the **SSM path itself** (consumed by `AuthClient`), not a resolved secret substituted into the yaml. Moving to `${awsps:...}` would change the field's role and the `AuthClient` contract — a behavior change, out of scope for this v1→v2 migration. No other SSM parameters (no gRPC creds — watermill-only).

## 6. cloud-sdk / commons dependencies & assumed gaps

| ID | Exercised? | How |
|---|---|---|
| **S-G2** | **Yes — primary consumer on the write side.** | `ZipPreprocessor` calls `StorageClient.putObject(bucket,key,bytes,metadata,contentType)` for every unzipped entry, replacing `WorkspaceService.putObjectWithMetaData(...)`. The **only** metadata-bearing S3 write in dispatcher; `copyInitialFileToWorkspace`'s `copyObject` is metadata-less and needs no new overload. |
| **W-G9** | **Yes — publishes and consumes `MetaData`/`Event`/tokens.** | Builds `MetaData` (`Projection.{MFT_ID,FILE_TYPE,S3_EVENT_CREATED_TIME,DISPATCHER_RECEIVED_TIME,PICKUP_FILENAME}`) and publishes to splitter/booking-bridge; reads `Event.Token.{MFT_ID,FILE_TYPE,ORIGINAL_FILE_SIZE,INBOUND_S3_FILE_NAME,XLOG_ID,ORIGINAL_FILE_NAME,PICK_UP_QUEUE,DROP_OFF_QUEUE}` and calls `logCloseRunEvent(...)`. Needs the **constant-parity** fix (`Event.Token.ORIGINAL_FILE_SIZE` used directly) for source compilation. W-G9.1 (builder round-trip) doesn't block dispatcher directly (no `Annotations` set), but it uses the same `Event`/`MetaData` classes, so it depends on W-G9 landing before/with its migration. |
| **X-G7** / **X-G8** | No | no email; no ES/Jest. |
| **C-G6** | Optional | §5.3 composition works without it. |
| **O-G1/O-G3** | Not depended on | dispatcher keeps `AsyncDispatcher` (appianway-commons) and its **local** `S3EventParser`; O-G3 promotion is a future optional additive move — tracked, not required. |

**Consumes from commons:** `ConfigProcessingServerCommand` + transforms, `networkservices.*` (`AuthClient`, `IntegrationProfileService`, `IntegrationProfileFormatService`), health base.
**Consumes from cloud-sdk-api/aws:** `StorageClient` (+ S-G2), `MessagingClient[String]` (+ `QueueMessage[String]`), `NotificationService`, `notification.workflow.{MetaData,Event,EventLogger,EventPublisher}` (+ W-G9 constants).

## 10. Risks & mitigations

| Risk | Mitigation |
|---|---|
| S3-event JSON shape mismatch after dropping v1 `S3EventNotification` (dispatcher-local parser is hand-rolled) | Captured-event fixtures (raw + SNS-wrapped) locked as golden tests; explicit URL-decode/zero-byte/missing-Records cases |
| `URLDecoder.decode` regression on keys with `+`/`%2F`/spaces | Explicit test cases mirroring v1 exactly |
| `software.amazon.awssdk.utils.IoUtils` vs v1 `IOUtils` stream-close semantics differ in the unzip loop | Unit-test the entry-copy path; verify streams closed identically; Guava `ByteStreams.toByteArray` fallback if behavior differs |
